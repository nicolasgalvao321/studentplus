1. Apresentação e Objetivo

O Student+ é um ecossistema completo de gestão e organização escolar desenvolvido em Flutter. A plataforma integra em tempo real quatro perfis de acesso distintos: Aluno, Professor, Responsável (Pais) e Funcionário (Secretaria/Staff).

Entre os principais recursos, o sistema oferece controle de frequências com alertas visuais, acompanhamento de tarefas, resumo de desempenho, mural de recados, cardápio da cantina escolar, gestão financeira com emissão de boletos, escala de limpeza para a equipe administrativa e um módulo de chat em tempo real estilo WhatsApp para comunicação direta entre a comunidade escolar.

2. Tecnologias Utilizadas

  • Flutter & Dart: Framework e linguagem para desenvolvimento multiplataforma (Web/Mobile).
  • Firebase Authentication: Registro, login seguro e controle de acesso baseado em papéis (roles).
  • Cloud Firestore: Banco de dados NoSQL em tempo real para sincronização de notas, boletos, recados e mensagens.
  • HTML5 & CSS3: Linguagens estruturais utilizadas para a criação deste manual técnico.

3. Requisitos e Instalação

  1. Instalar o SDK do Flutter (versão 3.x ou superior).
  2. Clonar este repositório do projeto.
  3. Executar o comando flutter pub get no terminal para baixar todas as dependências.
  4. Executar a aplicação com flutter run no emulador ou navegador Web.

5. Estrutura do Cloud Firestore

Os dados são gerenciados com regras de acesso por perfil e isolamento de sessão:

  • users/{uid}: Guarda o perfil do usuário (role: aluno, professor, responsavel, funcionario), nome e e-mail.
  • users/{alunoUid}/disciplinas: Armazena o nome da matéria, professor, quantidade de faltas e limite máximo (maxFaltas).
  • users/{alunoUid}/tarefas: Armazena o título da atividade, disciplina vinculada, prazo e status de conclusão.
  • users/{alunoUid}/mensalidades: Registra a lista de boletos (valor, vencimento, título e status de pagamento pago/pendente).
  • users/{alunoUid}/justificativas: Registra pedidos de abono de faltas e links de atestados enviados à Secretaria.
  • cantina: Coleção global contendo a lista de alimentos cadastrados no cardápio e seus respectivos preços.
  • recados: Coleção contendo avisos gerais e comunicados publicados por professores ou coordenação.
  • chats: Coleção de conversas com lista de participantes, nomes dos envolvidos, ultimaMensagem e data de atualização.
  • chats/{chatId}/mensagens: Subcoleção que contém o histórico de mensagens enviadas (remetenteUid, texto e timestamp).

6. Guia de Manutenção

Como alterar as cores principais do aplicativo?

Abra os arquivos em lib/screens/ ou o tema principal e modifique os códigos de cores hexadecimais:

  • Azul Acadêmico (Aluno/Tema Base): Color(0xFF0E3B68)
  • Verde Mensagens (WhatsApp): Color(0xFF075E54) e Color(0xFF25D366)
  • Laranja (Destaques e Cantina): Color(0xFFFF6B00) ou Colors.orange.shade800
  • Roxo / Azul Escuro (Módulo Staff / Professor): Colors.purple.shade800 e Colors.indigo

Como alterar as permissões de edição da Cantina Escolar?

A tela CantinaScreen utiliza a propriedade isStaff para controlar a exibição dos controles de adição e remoção:

  • Modo Edição (Funcionários/Staff): Chame a tela com CantinaScreen(isStaff: true). O botão flutuante "+ Novo Lanche" e os ícones de remoção estarão visíveis.
  • Modo Leitura (Alunos/Professores): Chame a tela com CantinaScreen(isStaff: false). O cardápio será exibido apenas para consulta.

Como garantir o isolamento correto das conversas no Chat?

Ao abrir a tela ListaChatsScreen a partir dos painéis principais, passe sempre o UID e o Nome do usuário ativo via construtor (ex: ListaChatsScreen(meuUid: usuarioUid, meuNome: usuarioNome)). Isso impede que a troca de contas no navegador sobreponha a sessão da aba.
