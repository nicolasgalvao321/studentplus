1. Apresentação e Objetivo

O Student+ é uma aplicação desenvolvida em Flutter para gestão e organização da vida escolar dos estudantes. Permite o controlo de disciplinas, acompanhamento de tarefas com estado de conclusão e um painel de resumo em tempo real.

2. Tecnologias Utilizadas

  • Flutter & Dart: Framework e linguagem para desenvolvimento mobile/web.
  • Firebase Authentication: Registo e login seguro de utilizadores.
  • Cloud Firestore: Banco de dados NoSQL em tempo real.
  • HTML5 & CSS3: Criação desta documentação técnica.

3. Requisitos e Instalação

  1. Instalar o SDK do Flutter (versão 3.x ou superior).
  2. Clonar este repositório do GitHub.
  3. Executar o comando flutter pub get para baixar as dependências.
  4. Executar a aplicação com flutter run.

4. Estrutura de Pastas do Código

lib/
├── models/       # Estruturas e modelos de dados
├── screens/      # Ecrãs (Login, Register, Home, Disciplinas, Tarefas, Resumo)
├── services/     # Serviços de integração (Firebase Auth e Cloud Firestore)
└── main.dart     # Ponto de entrada da aplicação

5. Estrutura do Cloud Firestore

Os dados estão organizados por utilizador (isolamento por UID):

  • users/{uid}/disciplinas: Guarda o nome, professor, faltas e limite.
  • users/{uid}/tarefas: Guarda o título, disciplina, data limite e estado de conclusão.

6. Guia de Manutenção

Como alterar as cores principais do aplicativo?

Abra os ficheiros dentro da pasta lib/screens/ e modifique as cores hexadecimais principais:

  • Azul Académico (Principal): Color(0xFF0E3B68)
  • Laranja (Destaque): Color(0xFFFF6B00)

Como adicionar um novo campo no formulário de Tarefas?

  1. Adicione o novo controlador em lib/screens/tarefas_screen.dart.
  2. Inclua o novo parâmetro no método adicionarTarefa em lib/services/firestore_service.dart.
